Available in desktop Chrome. Codex’s embedded browser currently supports the popup and a workspace tab instead.

Runs in your browser

TabPilot runs the agent inside this extension by default. Add your own model API key below, choose a tab, and start a task. No terminal, pairing token, or local server is required.

Keep Chrome running for scheduled tasks. Closing the workspace does not stop a task. Browser exit or extension reload interrupts active work; review it before resuming. Missed schedules are checked when the extension next runs. After a browser restart, review saved tasks and choose their current tabs before resuming.

Tab access

All web tabs have access by default. Revoke access for any tab below. Chrome-protected pages are unavailable.

Approvals and alerts

Routine searches, navigation and ordinary clicks run without interruption. Approval is for payments, purchases, sending or publishing content, destructive changes and sensitive account changes. The agent can also ask for missing information or help. Declining a request pauses its task and related specialists until you explicitly resume or give a new task.

Native notifications and background audio depend on browser support. A waiting task always appears in the workspace.

Credential storage

Task history and page observations are stored separately in the browser database. Upgrading preserves earlier saved tasks and history.

By default, credentials last for this browser session. Remembering saves them in this extension’s local storage, never Chrome sync. Local storage is not an encrypted vault. Keys are sent only to their selected API provider; page text and screenshots used by the agent go to that provider.

Leave credential fields blank to keep existing values. Use the removal options to clear them. Keys and tokens stay masked. Saved destinations are shown so you can check them. Developer server mode uses its own .env.local instead.

Advanced settings

Run limits bound time and model usage. A turn is a model round, which may include tool calls. Tasks can continue from saved progress between stages; reaching a limit does not mean the task succeeded.

Changes apply to the next run. CLI model settings remain independent.

Developer settings

Use the optional local server for external CLI or MCP clients and downloads to an absolute local folder. Normal browser tasks run in the extension and need no server. The two modes keep separate model settings, credentials, tasks, and history; switching does not copy credentials.
